# Abstergo LLC homepage UI — staged prototype

A static, local-first redesign concept for the public Abstergo LLC homepage.

## Scope boundary

This is a visual and interaction prototype only. It does not alter the live website, collect submissions, claim client results, or connect to any private service. Calls to action deliberately open an email conversation with `atlas.abstergo@gmail.com`.

## Launch

From this directory:

```bash
python -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173`.

## Verification intent

- Real Abstergo artwork is copied from the authorized iCloud asset directory.
- Responsive navigation works at mobile width.
- No credentials, tracking, forms, analytics, or third-party application APIs are included.

No publishing or deployment has been performed.
